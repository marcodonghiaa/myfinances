What the publisher sees

Nothing. There is no Alopex server between your bank and your database. The data goes from Enable Banking straight into your own Supabase project.

You stay in control

Every piece runs under your own accounts, and nothing on the bank side can be written to.

Your data lives in your Supabase

Postgres under your account, Row Level Security on every table. The dashboard uses only the publishable key; the service-role key stays in the sync scripts and Edge Functions.

Read-only by design

PSD2 account-information access and a read-only Coinbase key. Alopex cannot move money, and a database trigger blocks edits to bank-sourced fields.

Updates you review

Updates arrive as pull requests on your own copy. Nothing changes until you read and merge them. Sync logs hold counts only, never names or amounts.

  • Enable Banking, the licensed aggregator that relays data from your bank.
  • Supabase, Vercel and GitHub, under your own accounts.
  • Google Gemini, only if you add a key: transaction descriptions are sent for categorization and subscription detection.

Set up in about 30 minutes

All in the browser, all on free tiers. Nothing to install, no computer that has to stay on.

  1. Create free accountsGitHub, Supabase, Enable Banking and Vercel, plus an optional Gemini key. About 15 minutes, mostly Enable Banking's signup.
  2. Run setup in CodespacesOpen the repo in GitHub Codespaces and run ./setup.sh. It creates your database schema, deploys the functions, creates your login and turns on the sync.
  3. Deploy the dashboardClick Deploy with Vercel, paste the three values setup printed, and sign in. About 5 minutes.
  4. Link a bankConnect a bank from the Accounts page. Balances appear at once; transactions arrive with the next sync.

Who it is not for

You bank outside Europe. Bank sync is PSD2 only. No Plaid, SimpleFIN or US/Canadian banks.

You want someone else to run it. You host it, apply updates and renew bank consent every 180 days.

You want real-time balances. Sync runs every 6 hours, because banks cap unattended access at about 4 calls a day per account.

You want budgets, goals or forecasts. Not today. Alopex tracks net worth, spending, subscriptions and holdings.

You want broker sync. You enter holdings; prices update automatically. Coinbase is the only exchange that syncs balances.

Frequently asked questions

Is there an open-source alternative to Finary?

Yes. Alopex is an MIT-licensed, self-hosted net worth tracker that combines European bank accounts, stock and ETF holdings and crypto in one dashboard. You run it yourself and the data stays in your own Supabase project instead of a company's servers.

How is Alopex different from Firefly III or Actual Budget?

Firefly III and Actual Budget are budgeting tools; Alopex is a net worth tracker. It puts bank accounts, stock and ETF holdings and crypto in one daily total, and syncs European banks through Enable Banking. It does not offer budgets the way Actual does, and Firefly III and Actual do not track investment prices.

Is Alopex free?

The software is free under the MIT license. The default setup runs on free tiers of GitHub, Supabase, Vercel and Enable Banking (for your own accounts), with an optional Gemini key. Those limits are set by each provider and can change.

Which banks does Alopex support, and how long does access last?

Any of the 2000+ European banks available through Enable Banking, including Revolut, Wise and Fineco. PSD2 consent lasts 180 days: the dashboard shows a Renew access banner two weeks before it ends and sends push reminders, and you renew from the Accounts page without losing history.

Do I need a server to run Alopex?

No. The default setup runs the sync on GitHub Actions and the dashboard on Vercel, so no computer has to stay on. Setup takes about 30 minutes in the browser using GitHub Codespaces. Docker is an option if you want to run it on your own machine or home server.

Does Alopex work with US banks?

No. Bank sync uses PSD2, so it only covers European banks. You can still add US stocks and ETFs by ticker, track crypto, and show totals in USD.

Can Alopex move money or make payments?

No. It uses PSD2 account information access, which is read-only, and the Coinbase integration uses a read-only API key. The app reads balances, transactions and prices and never initiates payments.

Who can see my financial data in Alopex?

You, and anyone you create a login for on your own install. The data sits in your own Supabase project with Row Level Security, and the publisher has no access to it. Enable Banking relays bank data, and if you add a Gemini key, transaction descriptions are sent to Google for categorization and subscription detection.
