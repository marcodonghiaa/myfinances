What is MyFinances?

MyFinances is an open-source, self-hosted net worth tracker for people with European bank accounts. It syncs balances and transactions read-only from 2000+ banks over PSD2 (via Enable Banking), prices your stocks and crypto, and stores everything in your own Supabase project. It is released under the MIT license.

Features

Everything runs on your accounts. Nothing passes through a MyFinances server, because there isn't one.

Bank sync over PSD2

Connects Revolut, Wise, Fineco and 2000+ other European banks through Enable Banking, and syncs every 6 hours.

One net worth figure

Bank balances, portfolio and crypto add up to a single daily total, shown in EUR, USD or GBP using daily ECB rates.

Portfolio and crypto prices

Add holdings by name, ticker or ISIN. Prices come from Yahoo Finance and CoinGecko; Coinbase balances sync with a read-only key.

Rules-first categorization

Your own rules run first, Gemini handles the rest if you add a key, and categories you set by hand are never overwritten.

Subscription detection

Each transaction is marked Subscription or One-time, and the Subscriptions page shows billing frequency and true monthly cost.

Transfers and refunds handled

Transfers between your own accounts don't count as income, and card refunds are paired with the original charge so neither counts as spend.

"Worth it?" prompts

After a discretionary purchase you get a Web Push notification asking whether it was worth it. The answer is stored on the transaction.

Installable PWA

Add it to your phone's home screen, get push notifications, and import past months of net worth or spending from a CSV.

Screens

Number-first design: every screen opens on one exact figure. Light and dark follow your system.

How it works

About 30 minutes, all in the browser. Nothing to install, no computer that has to stay on.

  1. Create free accountsGitHub, Supabase, Enable Banking and Vercel, plus an optional Gemini key. About 15 minutes, mostly Enable Banking's signup.
  2. Run setup in CodespacesOpen the repo in GitHub Codespaces and run ./setup.sh. It creates your database schema, deploys the functions, creates your login and turns on the sync.
  3. Deploy the dashboardClick Deploy with Vercel, paste the three values setup printed, and sign in. About 5 minutes.
  4. Link a bankConnect a bank from the Accounts page. Balances appear at once; transactions arrive with the next sync. Prefer your own hardware? Docker runs both apps.

Privacy and security

Your money data is the most sensitive data you have. Here is exactly where it goes.

Where your data lives

In your own Supabase project (Postgres). Every table has Row Level Security scoped to your user. The dashboard uses only the publishable key; the service-role key stays in the sync scripts and Edge Functions.

Read-only access

PSD2 account information access only: MyFinances reads balances and transactions and cannot move money. Coinbase uses a read-only key. A database trigger stops bank-sourced fields from being edited.

What the publisher sees

Nothing. There is no MyFinances server between your bank and your database, and the publisher has no access to your Supabase project, keys or data.

Who else is involved

  • Enable Banking, the licensed aggregator that relays data from your bank.
  • Supabase, Vercel and GitHub, under your own accounts.
  • Google Gemini, only if you add a key: transaction descriptions are sent for categorization.
  • Your fork's Actions run list is public; sync logs hold counts only, never names or amounts.

Who it is not for

The trade-offs, up front.

  • You bank outside Europe. Bank sync is PSD2 only. No Plaid, SimpleFIN or US/Canadian banks.
  • You want someone else to run it. You host it, apply updates and renew bank consent every 180 days.
  • You want real-time balances. Sync runs every 6 hours, because banks cap unattended access at about 4 calls a day per account.
  • You want budgets, goals or forecasts. Not today. MyFinances tracks net worth, spending, subscriptions and holdings.
  • You want broker sync. You enter holdings; prices update automatically. Coinbase is the only exchange that syncs balances.

FAQ

Is there an open-source alternative to Finary?

Yes. MyFinances is an MIT-licensed, self-hosted net worth tracker that combines European bank accounts, stock and ETF holdings and crypto in one dashboard. You run it yourself and the data stays in your own Supabase project instead of a company's servers.

Can I self-host a net worth tracker with European bank sync?

Yes. MyFinances syncs balances and transactions from 2000+ European banks over PSD2 through Enable Banking, and runs on your own Supabase, GitHub Actions and Vercel accounts or on Docker. Setup takes about 30 minutes in the browser using GitHub Codespaces.

Is MyFinances free?

The software is free under the MIT license. The default setup runs on free tiers of GitHub, Supabase, Vercel and Enable Banking (for your own accounts), with an optional Gemini key. Those limits are set by each provider and can change.

Does MyFinances work with US banks?

No. Bank sync uses PSD2, so it only covers European banks. You can still add US stocks and ETFs by ticker, track crypto, and show totals in USD.

Which banks does MyFinances support?

Any of the 2000+ European banks available through Enable Banking, including Revolut, Wise and Fineco. You link a bank from the Accounts page, and access lasts 180 days before you renew it.

Can MyFinances move money or make payments?

No. It uses PSD2 account information access, which is read-only, and the Coinbase integration uses a read-only API key. The app reads balances, transactions and prices and never initiates payments.

Who can see my financial data?

You, and anyone you create a login for on your own install. The data sits in your own Supabase project with Row Level Security, and the publisher has no access to it. Enable Banking relays bank data, and if you add a Gemini key, transaction descriptions are sent to Google for categorization.

How is MyFinances different from Firefly III or Actual Budget?

Firefly III and Actual Budget are budgeting tools whose European bank sync relied on GoCardless Bank Account Data, which has closed new signups. MyFinances focuses on net worth across banks, investments and crypto, and syncs European banks through Enable Banking. It does not offer budgets the way Actual does.

Do I need a server or Docker?

No. The default setup runs the sync on GitHub Actions and the dashboard on Vercel, so no computer has to stay on. Docker is an option if you want to run it on your own machine or home server.

Can I try it without connecting a bank?

Yes. The live demo runs on generated fake data in your browser, with no sign-up. It never touches a real account.
